## AI Engineering Practices

AI-generated or AI-assisted work is treated as an engineering input rather
than an automatically trusted result.

Practices include:

- Independent validation of generated code
- Syntax and compile checks
- Automated testing
- Git diff review
- Source-integrity verification
- Deterministic validation where practical
- Checkpointing before significant changes
- Comparing proposed changes against known-good baselines
- Separating experimental work from production promotion
- Preserving reproducible evidence of successful results
