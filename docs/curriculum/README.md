# Curriculum Documentation

This directory contains module-level documentation for the DataExpert.io Community Edition curriculum as implemented and evidenced in this repository.

The academy curriculum is organized by **modules**, while the repository is largely organized by **implementation week**. These systems are not equivalent.

See:
- `../../CURRICULUM.md`
- `../../CURRICULUM_TRACEABILITY.md`

Each module page records official scope, repository implementation, evidence, validation, demonstrated skills, and any mapping caveats.
