# Submission Lessons — Week 4

## Pre-Submission Checklist

- [ ] Enumerate every numbered assignment requirement.
- [ ] Map every requirement to an explicit deliverable.
- [ ] Confirm the number of required outputs.
- [ ] Confirm every requested top-1 answer has its own query.
- [ ] Validate ordering columns against the exact question.
- [ ] Validate aggregation grain.
- [ ] Validate window frame semantics.
- [ ] Validate edge-case handling.
- [ ] Run `git diff --check`.
- [ ] Build the required submission ZIP.
- [ ] Run `unzip -t` against the ZIP.
- [ ] Verify expected file count inside the ZIP.
- [ ] Preserve the submitted state with a Git tag.
- [ ] Keep post-grade remediation separate from the graded baseline.

## Week 4 Lesson

The main Week 4 deduction was not caused by incorrect analytical logic.

The issue was deliverable completeness.

Queries 3, 4, and 5 could be derived from Query 2, but they were not supplied
as explicit query outputs.

Future assignments should therefore be validated against both:

1. semantic correctness
2. submission completeness
