# Week 5 — Data Pipeline Maintenance

This directory contains the DataExpert Boot Camp Week 5 Data Pipeline Maintenance homework.

## Assignment scope

The exercise models a four-person data engineering team responsible for five production data pipelines across:

- Profit
- Growth
- Engagement

The submission covers:

- primary and secondary pipeline ownership;
- fair on-call rotation;
- holiday coverage;
- investor-reporting pipeline runbooks;
- potential pipeline failure scenarios.

## Graded deliverable

The graded deliverable is:

`submission/data_pipeline_maintenance.md`

## Project structure

The project is organized into the following directories:

- `docs/` — supporting documentation
- `notes/` — working notes
- `reference/` — reference material
- `scripts/` — project and validation scripts
- `submission/` — graded homework deliverable
- `validation/logs/` — validation logs
- `validation/results/` — validation results

## Submission contents

The graded submission documents:

1. ownership assignments for all five pipelines;
2. primary and secondary owner responsibilities;
3. a fair rotating on-call schedule;
4. holiday and planned-time-off coverage;
5. runbooks for the three investor-reporting pipelines;
6. potential failure scenarios across all five pipelines;
7. operational handoff and escalation expectations.

## Required pipelines

The homework addresses:

- Unit-Level Profit
- Aggregate Profit
- Aggregate Growth
- Daily Growth
- Aggregate Engagement
